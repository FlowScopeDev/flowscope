## How to be added

Open a pull request or issue and, once it is merged or resolved, add a line to the list above in your
own pull request:

```text
- [Your Name](https://github.com/your-handle) (@your-handle): what you contributed
```

For code contributors, GitHub also lists you automatically on the repository's
[Contributors graph](https://github.com/FlowScopeDev/flowscope/graphs/contributors). This file is for
credit that the graph cannot show, such as testing, ideas, and documentation. Please do not add email
addresses.
